<h1 align="center">Antarctic</h1>

<p align="center">Cool colors for your code. Light and dark themes for your development tools.</p>

Inspired by the ice and deep waters of the South Pole, Antarctic combines blue-gray neutrals with teal, jade, amethyst, crimson, and amber accents. Start with the original light theme or choose its dark companion, then carry the same palette across your editor, terminal, and shell prompt.

## Two palettes, one identity

**Antarctic Light** pairs snowy backgrounds with darker text and accents. **Antarctic Dark** uses deep blue-gray backgrounds with lighter text and accents. Both share the same color families, adapted to their backgrounds.

Text and accent colors in the palettes meet at least **4.5:1 contrast** against each variant's main and panel backgrounds. Surface and border colors serve different roles; application overrides, transparency, and terminal color conventions can affect the final appearance.

## Get started

1. Choose your editor, terminal, or prompt from the table above.
2. Follow its README to download and install the theme.
3. Select **Antarctic Light** or **Antarctic Dark**, or use the configuration name shown in that guide.

## Help and feedback

If a theme does not appear, check the file location and activation steps in its port's README. If colors look different, check your application's existing color overrides and use the matching light or dark terminal background.

Report installation problems or color issues in the relevant port's GitHub Issues. Include the application version, operating system, theme variant, and a screenshot or small code sample when possible.

## Contribute a port

New ports and improvements are welcome. Use the palettes above as the foundation, include both variants, and provide simple installation instructions. Check the theme in the target application and document which parts of its interface are supported.
